# 🛍️ SpectSearch — Приложение для мониторинга цен

SpectSearch — это современное веб-приложение для отслеживания цен на товары в различных украинских и российских интернет-магазинах. Отслеживайте изменения цен, настраивайте оповещения и никогда не упускайте выгодные предложения.

## ✨ Возможности

- 📊 **Мультимагазинное отслеживание цен** — Мониторинг товаров из украинских (Rozetka, Allo, Comfy, Citrus, Epicentr) и российских (DNS, M.Video, Eldorado, Citilink, Ozon, Wildberries) магазинов
- 📈 **Графики истории цен** — Красивая визуализация sparkline с 15% отступами для стабильности
- 🔔 **Умные оповещения** — Получайте уведомления когда цена опускается ниже вашей целевой
- 🌐 **Автоматический парсинг** — Просто вставьте URL товара и приложение автоматически извлечет название и цену
- ⭐ **Избранное** — Отмечайте товары как избранные для быстрого доступа
- 📝 **Логи изменения цен** — Отслеживайте каждое значительное изменение цены с подробными логами
- 🎨 **Современный UI** — Элегантный интерфейс с плавными анимациями и адаптивным дизайном
- 🔄 **Автообновление** — Фоновый планировщик проверяет цены каждые 30 минут
- 🖼️ **Превью изображений** — Изображения товаров отображаются 48x48px в формах, 180x180px в модалках, 360x360px в просмотре товара
- 📱 **Мобильная адаптация** — Отлично работает на всех устройствах

### Требования

- Python 3.10 или выше
- pip менеджер пакетов

### Установка

1. Склонируйте репозиторий:
```bash
git clone <url-вашего-репозитория>
cd SpectSearch
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python app/main.py
```

4. Откройте браузер и перейдите по адресу:
```
http://127.0.0.1:5000
```

### Переменные окружения

Создайте файл `.env` (опционально, см. `.env.example`):

```env
DATABASE_URL=sqlite:///./price_monitor.db
SECRET_KEY=your-secret-key-here
```

## 📦 Технологический стек

### Backend
- **FastAPI** — Современный, быстрый веб-фреймворк для создания API
- **SQLAlchemy** — SQL инструментарий и Object-Relational Mapping (ORM)
- **SQLite** — Встроенная база данных для хранения данных
- **httpx** — HTTP клиент для загрузки страниц товаров
- **BeautifulSoup4** — HTML/XML парсер для веб-скрапинга
- **APScheduler** — Продвинутый планировщик Python для фоновых задач

### Frontend
- **Vanilla JavaScript** — Без зависимостей от фреймворков, чистый JS
- **CSS3** — Современный CSS с кастомными свойствами и анимациями
- **Chart.js** (через sparkline) — Визуализация истории цен

### Веб-скрапинг
- **Rozetka API** — Прямая интеграция API для быстрого и надежного получения цен
- **CSS Селекторы** — Резервный парсинг для всех поддерживаемых магазинов
- **JSON-LD поддержка** — Извлечение структурированных данных Schema.org

## 📖 Использование

### Добавление товара

1. Нажмите кнопку "Добавить товар"
2. Вставьте URL товара из любого поддерживаемого магазина:
   - **Украинские:** Rozetka, Allo, Comfy, Citrus, Epicentr
   - **Российские:** DNS Shop, M.Video, Eldorado, Citilink, Ozon, Wildberries
3. Добавьте URL изображения товара (опционально)
4. Нажмите "Парсить" чтобы автоматически заполнить название и цену
5. Сохраните товар

### Настройка оповещений

1. Откройте любой товар
2. Перейдите на вкладку "Оповещения"
3. Нажмите "Добавить оповещение"
4. Введите вашу целевую цену
5. Получайте уведомления когда цена опустится ниже вашей целевой

### Просмотр истории цен

1. Откройте любой товар
2. Перейдите на вкладку "История"
3. Просмотрите sparkline график показывающий изменения цен во времени
4. Посмотрите все исторические точки цен в таблице ниже

### Управление избранным

1. Нажмите иконку ⭐ на любой карточке товара чтобы добавить/удалить из избранного
2. Фильтруйте по избранному в главной панели

## 🔧 Разработка

### Сброс базы данных

Чтобы очистить все данные и начать заново:

```bash
# Сначала остановите сервер (Ctrl+C)
python clear_db.py
# Перезапустите сервер
python app/main.py
```

### Запуск с Docker

```bash
docker-compose up
```

Откройте приложение по адресу `http://localhost:5000`

### Интервал проверки цен

По умолчанию цены проверяются каждые 30 минут. Чтобы изменить это, отредактируйте `workers/scheduler.py`:

```python
scheduler.add_job(market_tick, "interval", minutes=30)  # Измените 30 на желаемый интервал
```

## 🐛 Известные проблемы

- **Rozetka блокирует API** — все endpoint возвращают 403 Forbidden из-за защиты от ботов. Используйте другие магазины (Allo, Comfy, Citrus работают отлично!)
- PowerShell многострочные команды вызывают крах с `ArgumentOutOfRangeException` (используйте отдельные .py файлы вместо этого)
- База данных блокируется когда сервер запущен (остановите сервер перед запуском `clear_db.py`)
